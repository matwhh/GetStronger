# Аудит продакшену — вересень 2026

- `PROMPT.md` — технічне завдання аудиту (правила, обсяг, формат знахідок, критерії вердикту).
- `agents/<домен>.md` — сирі звіти агентів Phase A, по одному на підсистему.
- `findings.json` / `findings.md` — зведені знахідки після дедуплікації й верифікації.
- `phase-a.md` — звіт Phase A з вердиктом.

Тека виключена з Vercel через `.vercelignore` (`docs/`); `tools/ci-hygiene.mjs`
стежить, щоб цей рядок не зник. Тут можуть лежати описи вразливостей —
на бойовий сайт вони не потрапляють.
